# 회귀 (가제)

**완결형 3화 로맨스 회귀물.** 서툰 모태솔로와의 썸이 3화 만에 끝나고, 실패하면 1화로 회귀한다.

🔗 **프로토타입**: _(배포 후 링크 삽입)_

---

## 소개 (제출용 초안 · 500자 이하)

> 기존 AI 연인 서비스의 문제는 대화가 지루한 게 아니라 **내가 뭘 해도 결과가 같다는 것**입니다.
> AI는 항상 나를 좋아하고, 그 관계는 잃을 수 없습니다. 잃을 수 없는 관계는 소중해지지 않습니다.
>
> 「회귀」는 리스크를 되돌려 놓습니다. 상대는 연애를 해본 적 없어 서툴고, 무성의하게 굴면 호감도가
> 실제로 깎이고, 3화가 끝나면 관계는 정말로 끝납니다. 배드엔딩이면 1화로 회귀하는데,
> 회차가 쌓일수록 그는 이유를 모른 채 당신에게 익숙해집니다.
>
> *"이상하네요. 왜인지 모르겠는데, 당신 앞에서는 덜 떨려요."*
>
> 검증하려는 가설은 하나입니다. **애착은 다정함이 아니라 리스크에서 나온다.**

## 실행

```bash
pnpm install
pnpm dev      # 개발 서버
pnpm test     # 상태 엔진 로직 테스트
pnpm build    # 프로덕션 빌드
```

API 키는 서버리스 함수에서만 읽습니다. `.env.local`에 `ANTHROPIC_API_KEY`를 넣으세요.
`VITE_` 접두사를 붙이면 클라이언트 번들에 노출되므로 절대 사용하지 않습니다.

## 어떻게 만들었나

모든 개발은 Claude Code로 진행했습니다. 세션 기록은 [`transcripts/`](transcripts/)에 있습니다.

AI가 코드를 대량 생산할 때의 실패는 "틀린 코드"가 아니라 **"이해할 수 없게 불어난 코드"**로 옵니다.
그래서 앱보다 개발 환경을 먼저 만들었습니다.

| 위치 | 역할 |
|---|---|
| [`.claude/rules/`](.claude/rules/) | 매 세션 자동 로드되는 규칙 — 제품 불변식, 복잡도 예산, 안전 가드레일, 하드 제외 목록 |
| [`.claude/agents/`](.claude/agents/) | 구현자와 이해가 충돌하는 역할 — 대사 감수, 상태 엔진 QA, 스코프 판정 |
| [`.claude/skills/`](.claude/skills/) | 반복 절차 — 시나리오 작성, 자동 완주 시뮬레이션, 트레이드오프 기록, 출시 점검 |
| [`docs/`](docs/) | 컨텍스트와 결정 기록 |
