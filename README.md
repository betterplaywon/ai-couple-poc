# 회귀 (가제)

**완결형 3화 로맨스 회귀물.** 서툰 모태솔로와 연인이 되기까지가 3화 안에 끝나고, 실패하면 1화로 회귀한다.

🔗 **프로토타입**: _(배포 후 링크 삽입)_

---

## 소개 (제출용 초안 · 500자 이하)

> 기존 AI 연인 서비스의 문제는 대화가 지루한 게 아니라 **내가 뭘 해도 결과가 같다는 것**입니다.
> AI는 항상 나를 좋아하고, 그 관계는 잃을 수 없습니다. 잃을 수 없는 관계는 소중해지지 않습니다.
>
> 「회귀」는 리스크를 되돌려 놓습니다. 상대는 연애를 해본 적 없어 서툴고, 무성의하게 굴면 호감도가
> 실제로 깎이고, 3화가 끝나면 관계는 정말로 끝납니다. 배드엔딩이면 1화로 회귀하는데,
> 회차가 쌓일수록 그는 이유를 모른 채 당신에게 익숙해집니다.
>
> *"이상하네요. 왜인지 모르겠는데, 당신 앞에서는 덜 떨려요."*
>
> 다루는 구간은 **연인이 되는 과정**입니다. 트루엔딩에 닿으면 그가 먼저 연락해 오는
> 다음 날 아침까지 보여주고 끝납니다. 유한한 것은 서비스가 아니라 온보딩입니다.
>
> 검증하려는 가설은 하나입니다. **애착은 다정함이 아니라 리스크에서 나온다.**

## 실행

```bash
pnpm install
echo 'GEMINI_API_KEY=AIza...' > .env.local   # https://aistudio.google.com/apikey

pnpm dev      # 개발 서버 (api/chat.ts도 함께 뜹니다)
pnpm test     # 상태 엔진 로직 테스트
pnpm lint
pnpm build    # 프로덕션 빌드
```

API 키는 서버리스 함수에서만 읽습니다. `.env.local`에 `GEMINI_API_KEY`를 넣으세요.
`VITE_` 접두사를 붙이면 클라이언트 번들에 노출되므로 절대 사용하지 않습니다.

### 데모 모드 (키 없이 실행)

**키가 없거나 API 호출이 실패하면 규칙 기반 스크립트 응답으로 폴백합니다.** 이때도
호감도·감점·화 전환·엔딩·회귀는 실제와 **동일한 계약**으로 완주까지 돕니다.

> ⚠️ 데모 모드의 **대사는 AI가 생성한 것이 아닙니다.** 화면 하단에 그 사실을 표시합니다.
> 서사 품질은 이 모드로 평가할 수 없습니다 — 검증되는 것은 게임 메커니즘뿐입니다.

## 구조

```
src/engine/     상태 전이 순수 함수 — 호감도 클램프·화 전환·엔딩 분기·회귀. 여기만 테스트한다
src/scenario/   캐릭터 카드 · 3화 · 엔딩 대사 · 회차 각성 · 위기 대응 문구 · 프롬프트 조립
src/components/ 게이지 · 대화 · 입력 · 엔딩 화면
api/chat.ts     LLM 프록시 (1개). 프롬프트만 조립하고 원문을 그대로 돌려준다
```

**진행 제어는 코드, 연기는 LLM.** 모델은 `scene_advance` 신호만 주고, 화 전환과 엔딩 판정은
`src/engine/`이 턴 수와 임계값으로 결정합니다. 모델이 준 `affection_delta`는 클램프한 뒤 누적합니다.
상태 전이는 클라이언트 한 곳에만 있고, 서버는 상태를 들지 않습니다.

## 어떻게 만들었나

모든 개발은 Claude Code로 진행했습니다. 세션 기록은 [`transcripts/`](transcripts/)에 있습니다.

런타임 모델은 Gemini입니다 — 개발 도구(Claude Code)와 제품이 호출하는 모델은 별개입니다.
제공자 교체 때 바뀐 파일은 [`api/chat.ts`](api/chat.ts) 하나이고, 프롬프트·상태 엔진·UI는 그대로입니다
([#18](docs/03-tradeoffs.md)).

AI가 코드를 대량 생산할 때의 실패는 "틀린 코드"가 아니라 **"이해할 수 없게 불어난 코드"**로 옵니다.
그래서 앱보다 개발 환경을 먼저 만들었습니다.

| 위치 | 역할 |
|---|---|
| [`.claude/rules/`](.claude/rules/) | 매 세션 자동 로드되는 규칙 — 제품 불변식, 복잡도 예산, 안전 가드레일, 하드 제외 목록 |
| [`.claude/agents/`](.claude/agents/) | 구현자와 이해가 충돌하는 역할 — 대사 감수, 상태 엔진 QA, 스코프 판정 |
| [`.claude/skills/`](.claude/skills/) | 반복 절차 — 시나리오 작성, 자동 완주 시뮬레이션, 트레이드오프 기록, 출시 점검 |
| [`docs/`](docs/) | 컨텍스트와 결정 기록 |
