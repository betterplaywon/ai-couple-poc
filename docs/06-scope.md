### 남은 검증 (키가 있어야 가능)

| 무엇 | 왜 지금 못 했나 | 어떻게 |
|---|---|---|
| 임계값 튜닝 (40/74/75) | 엔딩 분포를 한 번도 못 봄 | `/playthrough` |
| `affection_delta` 분포 | 아첨 편향이 실제로 잡혔는지 미확인 | `/playthrough` — 감점 발생률 |
| JSON 파싱 실패율 (5% 상한) | 실호출 0회 | `/playthrough` |
| 대사 톤·희화화 여부 | 실호출 0회 | 직접 플레이 + `romance-director` 감수 |

> ⚠️ **트루엔딩 도달 가능성이 지금 설계상 빡빡하다.** 시작 30 → 트루 75는 +45가 필요한데
> 화당 6~8턴 × 3화 = 최대 24턴이고 delta 상한이 +3이다. 프롬프트가 "대부분의 턴은 0"을 지시하므로
> 1회차 트루는 거의 불가능할 수 있다. **의도(1회차에 어렵게)와 사고(도달 불가)의 경계는
> `/playthrough` 분포로만 판별된다.** 튜닝 손잡이는 시작값·트루 임계값·delta 상한 셋이다.

## Should — 시간이 남으면

| 항목 | 왜 나중인가 |
|---|---|
| 답장 텀 연출 (타이핑 인디케이터, 지연) | 몰입에 크게 기여하지만 Must가 다 된 뒤 |
| 감정 라벨 UI 표현 (색·아이콘) | 게이지만으로도 차별점은 전달됨 |
| 세션 지표 패널 (완주율·턴 수) | 발표용. `/playthrough`로 대체 가능 |
| 엔딩 화면 연출 | 텍스트만으로도 성립 |

## Won't — 이번 PoC에서 만들지 않는다

버린 게 아니라 **적어둔 것**이다. 제품화 단계에서 다시 꺼낸다.

### 하드 제외 (논의 없이 거절)

회원가입 · 로그인 · DB · 영속 저장(localStorage 포함) · 배포 인프라 작업 · 결제 ·
TTS/음성 · 이미지 생성 · 캐릭터 2명 이상 · 대화 저장/불러오기/이어하기

### 좋은 아이디어지만 범위 밖

| 아이디어 | 왜 지금은 아닌가 |
|---|---|
| 화별 선택지 분기 | 경우의 수가 급증해 모든 갈래의 대사 품질이 같이 나빠진다 ([#5](03-tradeoffs.md)) |
| AI가 먼저 연락 (푸시/비동기) | 매력적이지만 세션 밖 상태와 알림 인프라가 필요하다 |
| 4회차 이상 각성 심화 | 3회차에서 서사가 완결된다. 늘리면 회귀가 지루한 반복이 된다 |
| 캐릭터 커스터마이징 | 가설은 "리스크가 애착을 만든다"이지 "선택지가 재미를 만든다"가 아니다 |
| 대화 요약/기억 압축 | 총 20턴이라 필요 없다. 유한 서사의 부수 이득 |
| 트루엔딩 이후 일상 **대화** | 구간은 "연인이 되는 과정"까지다. 단, 연인이 된 다음 날은 고정 스크립트 에필로그로 **보여준다** (읽기 전용, 턴 없음) |
| 커플 사진 생성 (Kaze AI형) | 사진 생성기에는 연인이 없어 주제에서 오히려 멀어진다. Claude API는 이미지 생성 불가 — 별도 모델·업로드·스토리지가 필요하고 하드 제외 3건에 걸린다 ([#15](03-tradeoffs.md)) |

## 일정

**D1** — 뼈대와 엔진
- 상태 엔진 순수 함수 + vitest (M1)
- `api/chat.ts` + 구조화 출력 + 폴백 (M2)
- 최소 채팅 UI — 대화가 오가는 것까지 (M4 일부)
- 목표: **하루 끝에 대화가 된다**

**D2** — 서사와 루프
- 3화 시나리오 + 캐릭터 카드 (M3) ← `romance-director`
- 게이지·화 표시 (M4)
- 엔딩 3종 + 회귀 각성 (M5, M6)
- `/playthrough` 1차 실행 → 감점 발생률·엔딩 분포 확인
- 목표: **하루 끝에 완주가 된다**

**D3** — 다듬기와 제출
- `/playthrough` 결과로 임계값·프롬프트 튜닝
- AI 고지, 모바일, 에러 UI (M7)
- Should 항목 중 시간 되는 것
- `/ship-check` → 배포 (M8)
- transcripts 변환·커밋, README (M9, M10)

윗줄이 안 되는데 아랫줄을 손보고 있으면 순서가 틀린 것이다.
