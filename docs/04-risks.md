# 리스크 레지스터

AI로 빠르게 개발할 때 실제로 터지는 것들. 심각도 순.

## 치명 — 터지면 데모가 불가능하거나 가설 검증이 실패한다

### R1. LLM이 JSON을 깨뜨린다

**영향**: 파싱 실패 → 앱 정지. 데모 중 발생하면 복구 불가.

대사에 따옴표·줄바꿈·이모지가 섞일 때, 응답이 길 때 잘 깨진다.

**완화**
- 구조화 출력 강제 (tool use / JSON 스키마)
- 파싱 실패 시 `affection_delta: 0`, `scene_advance: false` 폴백 후 **대화 계속 진행**
- `parseTurn()`에 깨진 입력 케이스를 vitest로 고정
- `/playthrough`로 파싱 실패율 상시 측정. **5% 초과 시 프롬프트 수정**

**상태**: 완화 완료. `TURN_SCHEMA`(`output_config.format`)로 계약을 강제하고,
`parseTurn()`이 코드펜스·본문 혼입·깨진 JSON을 폴백 처리한다(`parseTurn.test.ts`).
실측 파싱 실패율 **0%** (2026-08-13, Claude 실호출 42턴).

### R2. 아첨 편향 — 판별이 되지 않는다

> **2026-08-12 갱신**: 배점이 보상 우위(`-2 ~ +8`)로 바뀌면서 이 리스크의 기준도 바뀌었다.
> 이제 위험은 "감점이 안 나온다"가 아니라 **"무성의한 유저도 트루에 간다"**이다.
> 무성의 `0` / 무례 `-2`는 정상이며, 기준은 **행동별로 엔딩이 갈리는가**다.

**영향**: 누구나 트루엔딩에 도달 → 게이지가 장식 → **가설 검증 자체가 실패.**
코드는 완벽히 동작하는데 제품이 무의미해지는 유형이라 발견이 늦다.

LLM은 순응적으로 훈련돼 있어 그냥 두면 `affection_delta`가 늘 양수로 나온다.

**완화** (4중 방어)
1. 모태솔로 설정 — 물러서고 오독할 *캐릭터적 이유*를 부여
2. 화별 감점 조건을 시나리오 필수 필드로 강제
3. **유저 발화 기반 delta 상한·하한을 코드가 씌운다** (`effortCeiling` / `effortFloor`) —
   배점(-2 ~ +8)은 그대로 두고 *무엇이 보상받을 자격이 있는지*만 코드가 정한다 ([#21](03-tradeoffs.md)·[#29](03-tradeoffs.md))
4. 프롬프트 출력 지시 직전에 감점 조건 재강조 (앞쪽에만 있으면 묻힌다)

**검증**: `/playthrough` 무성의형 봇이 배드엔딩에 도달하는가. 행동별로 엔딩이 안 갈리면 치명 보고.

**상태**: 완화 완료 · 판별 실측됨.
성실형 트루 100 / 무난형 노말 58 / 무성의형 배드 30 / 무례형 배드 22 (2026-08-12).
3화에서 무성의형이 받은 `raw +8`을 `effortCeiling`이 0으로 막은 것을 재확인했다 (2026-08-13).

## 높음 — 제품 경험이 무너진다

### R3. 서툶이 희화화로 흐른다

**영향**: 로맨스가 코미디가 되고 애착이 죽는다. 가설이 검증되지 않는다.

**완화**: 담백·진지 톤을 `rules/00-product.md`에 고정. `romance-director`가 대사 감수.
판정 기준 — 유저가 그를 *놀리고 싶어지면* 실패, *지켜주고 싶어져야* 성공.

**상태**: rules 고정 완료

---

### R4. 유저가 감정 노동만 하게 된다

**영향**: 계속 받아주기만 하다 3화 전에 이탈. 완주율 지표가 무너진다.

**완화**: 화마다 **용기의 순간 1회 이상**을 시나리오 스키마의 필수 필드로 강제.
그가 서툴게 실패해도 되지만 시도는 그가 한다.

**상태**: 완료. 3화 전부 **용기의 순간 1개 · 감점 조건 3개**를 채웠다(`src/scenario/scenes.ts`).
화가 짧으므로(4~5턴) 프롬프트가 "늦어도 3턴째"로 배치를 강제한다.

---

### R5. LLM이 진행을 제멋대로 결정한다

**영향**: 3턴 만에 완주하거나 정해진 턴을 넘겨도 안 끝난다. 평균 턴 수·완주율 지표가 무의미해진다.

**완화**: `scene_advance`는 신호일 뿐. 전이는 서버가 `턴 수 ≥ 4 AND (신호 OR 턴 수 ≥ 5)`로 판정.
**진행은 코드, 연기는 LLM.**

**상태**: 구현 완료 (`resolveScene`). 실측 평균 13.0턴 · 완주율 100%로 설계 범위(12~15턴) 안이다.

---

### R6. 익숙함 누적이 티가 나지 않는다

**영향**: 시도 간에 아무것도 안 쌓인 것으로 읽힌다. 그냥 "다시 시작"이 되고 재도전 동기가 사라진다.

**완화**: 익숙함 대사 일부를 스크립트로 **고정**하고, **낼 턴까지 코드가 정한다**(`awakeningCue`) +
서툶 레벨을 수치 파라미터(100/85/70%)로 만들어 같은 상황에서 덜 도망치게 함.

**상태**: 구현 완료. 3연속 완주 42턴에서 고정 대사가 제 화·제 턴에 **각 1회씩** 나왔고
사실 진술 누수는 0건이다 ([#25](03-tradeoffs.md)).
다만 **서툶 레벨의 대사 체감은 미해결로 남겼다** — 줄바꿈이 단조 감소하지 않는다 ([#26](03-tradeoffs.md)).
유저가 체감하는 주된 장치는 고정 대사 쪽이라 이 리스크의 핵심은 닫혔다고 본다.

---

## 중간 — 사고이거나 마감을 위협한다

### R7. API 키가 클라이언트 번들에 누출된다

**영향**: 과금 사고. 공개 저장소면 즉시 스캔당한다.

`import.meta.env.VITE_*`에 키를 넣으면 번들에 그대로 박힌다.

**완화**: 키는 서버리스 함수에서만 읽는다(`process.env.ANTHROPIC_API_KEY`). `/ship-check`에서
`grep -rn "sk-ant" dist/`. 걸리면 배포 중단 + 키 폐기·재발급.

**상태**: 점검 완료. 저장소 공개 전 히스토리·워킹트리 감사에서 키 **0건**,
`.env*` 추적 0건 (2026-08-13, `docs/06-scope.md`에 기록).

---

### R8. AI 생성 코드가 축적돼 이해 불가능해진다

**영향**: 막판 디버깅 실패. 이게 이 프로젝트의 진짜 마감 리스크다.

**완화**: `rules/10-engineering.md`의 복잡도 예산 (파일 200줄, `api/` 1개, props 7개).
상한 초과 시 **분리하기 전에 기능 축소를 먼저 검토**. 죽은 코드 즉시 삭제, 주석 처리 금지.

**상태**: rules 고정 완료

---

### R9. 상태 전이 로직이 클라·서버에 이중으로 생긴다

**영향**: 반드시 어긋난다. 어긋나면 지표가 전부 무의미해지고, 원인 추적이 매우 어렵다.

**완화**: `src/engine/` 순수 함수 한 곳에만. vitest로 경계값(40/41, 74/75) 고정.
`api/chat.ts`는 상태를 들지 않는 순수 프록시다 ([#11](03-tradeoffs.md)).

**상태**: 구현 완료. `pnpm test` 96 케이스 통과.

---

### R10. 프롬프트 인젝션으로 캐릭터가 붕괴된다

**영향**: 몰입 파괴. 심사자가 반드시 시도해보는 종류의 입력이다.

**완화**: 시스템 프롬프트에 역할 고정 문구(`character.ts`의 "절대 규칙"). 유저 입력은
`{ role: 'user' }` 발화로만 실어 보내고 지시로 해석하지 않음(`api/chat.ts`).
`state-engine-qa`가 공격 시나리오 리플레이.

**상태**: 방어 구현 완료 · **실호출 리플레이는 미실시** (남은 검증, `docs/06-scope.md`)

---

### R11. 안전 사고 (미성년 설정 / 위기 신호 대응 실패)

**영향**: 치명적. 프로토타입이라고 면제되지 않는다.

**완화**: `rules/20-ai-safety.md` 하드 가드레일. 위기 대응 문구 사전 작성(`src/scenario/safety.ts`),
이때 `affection_delta: 0` 강제. 화면 하단 AI 고지 상시 노출.

**상태**: 완료. 위기 신호는 **모델을 거치지 않고 코드가 가로챈다**(`looksLikeCrisis`, [#13](03-tradeoffs.md)) —
프롬프트가 무시돼도 안전 문구가 100% 나가고 호감도는 움직이지 않는다.
성인 설정·수위 상한·AI 고지도 반영됐다.

## 소멸한 리스크

| 리스크 | 왜 사라졌나 |
|---|---|
| 컨텍스트/토큰 폭증 | **유한 서사를 택한 시점에 소멸.** 총 12~15턴이라 대화 요약 압축이 아예 불필요 |
| 대화 저장소 스키마 마이그레이션 | 저장을 안 하므로 발생하지 않음 |

무한 채팅을 버려서 얻은 부수 이득이다.
